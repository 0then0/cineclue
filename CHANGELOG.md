# Changelog

Notable user-facing and contributor-facing changes are recorded here. Release tags identify
published versions; unreleased changes do not imply a production deployment.

## [Unreleased]

### Changed

- Standardized repository line endings, editor settings and ignored local files.
- Added structured bug, feature and data correction reports and a pull request template.
- Updated contributor, conduct and security guidance and linked the hosted application.
- Added CI cancellation for superseded runs and a per-job timeout. Production deployment
  and database operations remain manual.

## [0.1.0] - 2026-10-23

### Added

- Daily film puzzles with eight attempts, a shared answer and a reset at 00:00 UTC.
- Unlimited play with three difficulty levels, 42 collections and session restoration.
- Shareable film challenges and spoiler-free result sharing.
- A bundled catalog of 10,000 films with translated, original and alternative title search.
- Visual comparisons with posters, portraits, studio logos, flags and match indicators.
- Two hints, unlocked after three and seven unsuccessful guesses.
- English, Russian, Spanish, German, French, Japanese and Brazilian Portuguese interfaces.
- Responsive layouts, keyboard search, light and dark themes and local Daily statistics.
- Docker development setup, PostgreSQL 16–18 support and manual Netlify + Neon deployment.
